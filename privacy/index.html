1. About this website

retiverse.com is a simple static website run by Retiverse Games and hosted on GitHub Pages (GitHub, Inc.). You can read it without an account, and nothing on it is personalised.

2. No cookies, analytics or ads

This website does not set cookies and does not use analytics, advertising or tracking tools. Fonts, images and scripts are all served from retiverse.com itself, so your browser doesn't contact third parties when you read it.

3. Hosting and server logs

Like any web server, GitHub Pages receives your IP address and technical details of each request (such as browser type and the page requested) in order to deliver the site and keep it secure. GitHub processes this data under its own privacy statement: GitHub General Privacy Statement. We don't receive or use these logs to identify visitors.

4. Browser storage

If the site offers you the other language and you close that message, your browser remembers it for the current visit (session storage). This stays on your device and is deleted when you close the tab.

5. When you email us

If you write to us, we use your email address and message only to answer you, for example to help with a game or handle a data request. We keep the conversation only as long as we need it for that purpose.

6. Your rights

Depending on where you live (for example under the GDPR or Turkey's KVKK), you can ask to access, correct or delete personal data we hold about you, or object to its use. Email us at retiverse@gmail.com.
